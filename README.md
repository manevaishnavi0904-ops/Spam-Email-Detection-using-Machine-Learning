# Spam-Email-Detection-using-Machine-Learning
This project builds a machine learning-based spam detection system using NLP techniques to classify messages as spam or ham. It includes text preprocessing, feature extraction using TF-IDF, and model training with algorithms like Naive Bayes, achieving accurate and efficient message classification.

🔹 Project Overview
This project focuses on building a machine learning model to automatically classify messages as spam or ham (non-spam). With the increasing volume of digital communication, spam detection plays a crucial role in filtering unwanted and potentially harmful messages. This project applies Natural Language Processing (NLP) and supervised learning techniques to accurately identify spam messages.



🔹 Objectives
- Classify messages as spam or ham  
- Perform text preprocessing and cleaning  
- Convert text data into numerical features  
- Train and evaluate machine learning models  
- Improve classification accuracy using NLP techniques  



🔹 Dataset Description
The dataset consists of labeled messages:

- `label` – Indicates whether the message is spam or ham  
- `message` – Text content of the message  


🔹 Tools & Technologies Used
- Python  
- Pandas  
- NumPy  
- Scikit-learn  
- Natural Language Processing (NLP)  
- NLTK / SpaCy  
- Matplotlib / Seaborn  


🔹 Data Preprocessing
- Removed punctuation and special characters  
- Converted text to lowercase  
- Removed stopwords  
- Tokenization  
- Stemming / Lemmatization  


🔹 Feature Engineering
- Applied Bag of Words (BoW)  
- Used TF-IDF (Term Frequency–Inverse Document Frequency)  


🔹 Model Building
Machine learning algorithms used:
- Naive Bayes (primary model)  
- Logistic Regression *(optional)*  
- Support Vector Machine *(optional)*  


🔹 Model Evaluation
- Accuracy Score  
- Precision  
- Recall  
- F1-Score  
- Confusion Matrix  


🔹 Results
- Successfully classified spam and ham messages  
- Achieved high accuracy using NLP techniques  
- Naive Bayes performed well for text classification tasks  


🔹 Visualizations
- Word frequency distribution  
- Spam vs ham count plot  
- Confusion matrix heatmap
